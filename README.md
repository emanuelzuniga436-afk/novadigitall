# NOVA DIGITAL

Landing page para una agencia de diseño y automatización digital.

## Cómo abrirla localmente

1. Abre [index.html](index.html) directamente en tu navegador o usa un servidor local.
2. Para un servidor local simple:
   - `python -m http.server 8000`
   - Luego abre `http://localhost:8000`
